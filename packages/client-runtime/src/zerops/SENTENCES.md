- ZV1 — An agent's login is the viewer's only when the person on record as signing it in is the viewer; anybody else's sign-in makes it somebody else's
- ZV2 — A login with no sign-in on record, or read by a viewer nobody can name, is nobody's to run and never said to be somebody else's
- ZV3 — A login with no credential held is nobody's, and a turn on it is not held back
- ZV4 — A turn runs only on the viewer's own login or one with no credential: somebody else's login and an unrecorded one hold it
- ZV5 — Only a login somebody else signed in asks for the viewer's attention; an unrecorded one does not
- ZV6 — A sign-in the viewer started and that is still under way counts as theirs before the Mate records it; a colleague's under way does not
- ZV7 — A finished, failed or cancelled sign-in vouches for nobody by itself: only the Mate's record names its signer then
- ZV8 — A login's agent is read from its provider's driver, so a second Claude Code login spends Claude Code, and a provider Mate signs nobody in to spends none
- ZV9 — A service port's public origin carries no port segment on port 80 and its own port on every other port, as Zerops serves them
- ZV10 — A port has no public origin when its service's subdomain access is off, its scheme is not HTTP, or its project has no public subdomain
- ZV11 — An account's organizations are those it is an active member of, each once; an inactive membership or an invitation still waiting is not one of them
- ZV12 — Each of the account's organizations carries the account's own membership in it: that membership's id, its role and the rights it states
- ZV13 — An organization is offered as an invitation only while the account's membership in it waits for authorization and the account is not already an active member of it, each organization once
- ZV14 — A Mate flag typed into a service's variables reads as on for 1 or true in any letter case and with surrounding space, and as off for every other spelling
- ZV15 — A throttled Zerops answer tells its caller to wait as long as its Retry-After asks in seconds, never longer than ten minutes, and not at all when it asks nothing readable
