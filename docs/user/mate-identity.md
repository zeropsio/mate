# Mate in the interface

Mate's open-eyed mark appears in the sidebar, on the sign-in screen, above a new
thread, and in the browser tab. The sidebar mark returns to the thread overview.

On sign-in and new-thread screens, Mate wakes once. His eyes follow the mouse
anywhere in the window, then return to rest when the pointer leaves the window
or it loses focus. With reduced motion enabled
in your system, the mark stays still. On touch screens, no pointer reaction runs.

The mark identifies the app. Thread status labels, questions, and approvals tell
you what the coding agent is doing or what needs your attention.
