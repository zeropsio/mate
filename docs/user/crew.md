# Crew work after a restart

When Mate restarts during crew work, the crew carries on by itself once Mate is back. Each
crewmate picks up from the last step that finished: a turn the restart cut off continues in the
same crew copy, a check runs again, and a landing records that the work is already in Fen's code
or lands it again. A running crew keeps running. A request to show work on dev that you allowed
goes out first.

Some work waits for you instead, and its row says why: a copy you chose to rebuild, a turn you
sent in a conversation yourself, or work Mate can no longer start for its signer. Press
**Continue** to carry it on, or **Drop it** to cancel an interrupted task before landing. Drop it
keeps the task's files in its copy.

A crew copy that went missing comes back by itself when its saved work is all still there. If
some of it is gone, the row names what was lost and shows **Rebuild crew copy**, which rebuilds
only that crewmate's copy from its saved work.

If a conversation has a different copy selected, it shows **Conversation points elsewhere** with
both paths. **Use crew copy** switches that conversation to its crew copy. Your selection stays in
place until you press it.
