# Preview a public service

In a conversation, click any web link in a message, on an operation card or in the service map to open the website beside the chat. Links on the same origin reuse the service tab; other websites are named by their host. Each service has its own tab in the right panel. Clicking another URL for that service updates its tab. Switch between tabs without losing the page, reload it with the toolbar, or close it with the tab’s close button. The panel can be resized or maximized; on narrow screens it opens as a sheet.

Use Cmd/Ctrl-click or **Open in new tab** to open the public address in your browser. Sites that block embedding must be opened this way. The address bar shows the public entry URL; navigation inside a different-origin page cannot update it.

This is your interactive view of the public website. The **Browser** tab continues to show the agent’s separate browser session. Web and desktop use the same preview; native mobile and public-access menus outside the conversation retain external links.
